# NftDrift

NftDrift leverages High-Performance architecture for Real-Time data processing, utilizing Auto-Scaling and efficient Query Optimization within a modular Framework.

NftDrift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftDrift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
